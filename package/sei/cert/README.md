# SEI CERT Coding Standards

The SEI CERT Coding Standards are secure coding rules and recommendations developed by the CERT Division of
the Software Engineering Institute (SEI) at Carnegie Mellon University. They help developers avoid coding
errors that lead to vulnerabilities.

## What it includes

- **SEI CERT C Coding Standard:** rules and recommendations for C
- **SEI CERT C++ Coding Standard:** rules for C++
- **SEI CERT Oracle Coding Standard for Java:** rules and recommendations for Java
- **Other languages:** guidance for further languages and platforms such as Android and Perl
