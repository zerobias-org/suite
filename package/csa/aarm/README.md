# Autonomous Action Runtime Management (AARM)

Autonomous Action Runtime Management (AARM) is an open specification for securing actions taken by
AI agents at runtime. It is developed as a Cloud Security Alliance project, and defines what a
system must do to intercept, evaluate, authorize and record agent actions before they execute.

## What it includes

- **AARM Core:** Required (MUST) capabilities, from pre-execution interception to identity binding.
- **AARM Extended:** Additional (SHOULD) capabilities such as semantic drift tracking, telemetry
  export and least-privilege enforcement.
- **Conformance:** Requirements and a testing protocol for claiming conformance.
- **Threat coverage:** Threat classes such as prompt injection, data exfiltration and memory
  poisoning.
