# AI Controls Matrix (AICM)

The AI Controls Matrix is a vendor-agnostic control framework for cloud-based AI systems,
published by the Cloud Security Alliance (CSA). It builds on CSA's Cloud Controls Matrix.

## What it includes

- **Control objectives:** AI security control objectives grouped into security domains.
- **Mappings:** Mappings to other AI frameworks, such as ISO/IEC 42001, NIST AI 600-1 and
  the EU AI Act.
- **Implementation and auditing guidelines:** Guidance for model providers, application
  providers, AI customers and cloud service providers.
- **AI-CAIQ:** A questionnaire based on the matrix for self-assessment or vendor review.
