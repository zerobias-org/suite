# CSA IoT Security Controls Framework v2

The IoT Security Controls Framework is a set of security controls for enterprise IoT systems
that combine many types of connected devices, published by the Cloud Security Alliance (CSA)
IoT Working Group.

## What it includes

- **Security controls:** Controls for IoT systems ranging from low-impact to highly
  sensitive systems.
- **Control domains:** Controls grouped into domains, including Legal and Security Testing
  domains added in version 2.
- **Infrastructure allocations:** Mapping of controls to the components of an IoT
  architecture.
- **Guide:** A companion guide that explains how to use the framework.
