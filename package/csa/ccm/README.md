# Cloud Controls Matrix (CCM)

The Cloud Controls Matrix is a cybersecurity control framework for cloud computing, published
by the Cloud Security Alliance (CSA). It is used by cloud providers and customers to assess
and document cloud security controls.

## What it includes

- **Control specifications:** Cloud security controls organized into domains.
- **CAIQ:** The Consensus Assessments Initiative Questionnaire, a set of questions based on
  the controls.
- **Mappings:** Mappings from CCM controls to other standards and frameworks.
- **Implementation and auditing guidelines:** Guidance for applying and assessing the
  controls.
