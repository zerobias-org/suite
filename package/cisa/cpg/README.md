# Cross-Sector Cybersecurity Performance Goals (CPGs)

The Cross-Sector Cybersecurity Performance Goals are voluntary cybersecurity practices published by
the U.S. Cybersecurity and Infrastructure Security Agency (CISA). They are a baseline of
high-impact practices for critical infrastructure organizations of all sizes, for both IT and OT.

## What it includes

- **Goals:** Specific security practices, each tied to the risk it reduces.
- **NIST CSF alignment:** Goals organized by the NIST Cybersecurity Framework 2.0 functions,
  including Govern.
- **Sector-specific goals:** Related goals developed for individual critical infrastructure sectors.
