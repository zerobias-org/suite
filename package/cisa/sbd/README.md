# Secure by Design

Secure by Design is an initiative of the U.S. Cybersecurity and Infrastructure Security Agency
(CISA). It urges technology manufacturers to build security into their products from the start,
so customers are secure by default.

## What it includes

- **Principles:** Take ownership of customer security outcomes, embrace radical transparency and
  accountability, and lead from the top.
- **Secure by Design guidance:** Practices for manufacturers, such as memory-safe languages and
  eliminating default passwords.
- **Secure by Design Pledge:** Voluntary commitments by software manufacturers, such as increasing
  multi-factor authentication use and publishing a vulnerability disclosure policy.
