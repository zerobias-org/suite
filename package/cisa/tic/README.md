# Trusted Internet Connections (TIC)

Trusted Internet Connections (TIC) is a U.S. federal cybersecurity program run by the
Cybersecurity and Infrastructure Security Agency (CISA). It secures federal agency network traffic
and data, and its current guidance (TIC 3.0) supports cloud, remote and branch-office use.

## What it includes

- **Program Guidebook:** Overview of the TIC 3.0 program and how its documents fit together.
- **Reference Architecture:** Concepts such as trust zones and policy enforcement points.
- **Security Capabilities Catalog:** Universal and policy enforcement point security capabilities.
- **Use cases:** Guidance for traditional TIC, branch office, remote user and cloud scenarios.
