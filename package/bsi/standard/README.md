# BSI Standard 200-1

BSI Standard 200-1 "Management Systems for Information Security" is published by Germany's Federal
Office for Information Security (BSI). It defines general requirements for an information security
management system (ISMS) and is part of the BSI's IT-Grundschutz methodology.

## What it includes

- **ISMS requirements:** Components of an information security management system.
- **Management responsibility:** Management principles, resources and staff involvement.
- **Security process:** Planning, implementing, checking and improving information security.
- **Compatibility:** Alignment with ISO/IEC 27001; companion standards 200-2 (methodology),
  200-3 (risk analysis) and 200-4 (business continuity) build on it.
