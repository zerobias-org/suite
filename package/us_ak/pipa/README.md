# Alaska Personal Information Protection Act (PIPA)

The Alaska Personal Information Protection Act is an Alaska state law, codified at AS 45.48, that
sets rules for protecting the personal information of Alaska residents. It is enforced as part of
Alaska's consumer protection law.

## What it includes

- **Breach notification:** Notice to affected Alaska residents after a breach of the security of
  personal information.
- **Security freeze:** Consumer rights to place a security freeze on a credit report.
- **Social Security numbers:** Limits on the use and disclosure of Social Security numbers.
- **Disposal of records:** Requirements for disposing of records that contain personal information.
