# ISO/IEC 27002 - Information security controls

ISO/IEC 27002 provides a reference set of information security controls with implementation guidance.
It is published jointly by ISO and IEC and is used with ISO/IEC 27001.

## What it includes

- **Organizational controls:** Policies, roles, asset management, supplier relationships and incident
  management.
- **People controls:** Screening, awareness and training, and responsibilities.
- **Physical controls:** Secure areas, equipment and physical access.
- **Technological controls:** Access control, cryptography, logging, secure development and more.
- **Attributes:** Tags for filtering and grouping controls by different views.
