# ISO/IEC 24759

ISO/IEC 24759 specifies the methods testing laboratories use to check whether a cryptographic module
conforms to the requirements of ISO/IEC 19790. It is published jointly by ISO and IEC.

## What it includes

- **Test requirements:** Test methods for each requirement of ISO/IEC 19790.
- **Vendor evidence:** The documentation and evidence vendors must give to testing laboratories.
- **Self-check use:** Lets vendors prepare their modules before engaging a laboratory.
