# ISO/IEC 19790

ISO/IEC 19790 specifies security requirements for cryptographic modules used to protect sensitive
information in computer and telecommunication systems. It is published jointly by ISO and IEC.

## What it includes

- **Security levels:** Four increasing qualitative levels of security for cryptographic modules.
- **Requirement areas:** Requirements covering areas such as module specification, interfaces, roles and
  authentication, software and firmware security, physical security, and key management.
- **Testing link:** Conformance is tested with the methods in ISO/IEC 24759.
