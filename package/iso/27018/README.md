# ISO/IEC 27018 - Protection of PII in public clouds acting as PII processors

ISO/IEC 27018 gives guidelines for protecting personally identifiable information (PII) in public cloud
services that act as PII processors. It is published jointly by ISO and IEC and builds on
ISO/IEC 27002.

## What it includes

- **PII protection guidance:** Implementation guidance for ISO/IEC 27002 controls in a public cloud PII
  processing context.
- **Extended control set:** Additional controls for public cloud PII processors.
- **Processor obligations:** Guidance on areas such as customer instructions, disclosure, return and
  deletion of PII.
