# ISO/IEC 29100 - Privacy framework

ISO/IEC 29100 provides a high-level privacy framework for protecting personally identifiable
information (PII) in information and communication technology systems. It is published jointly by ISO
and IEC.

## What it includes

- **Common terminology:** Privacy terms used across the ISO/IEC privacy standards.
- **Actors and roles:** PII principals, PII controllers, PII processors and third parties.
- **Privacy safeguarding considerations:** Factors that shape privacy requirements.
- **Privacy principles:** Principles such as consent and choice, purpose limitation, data minimization
  and accountability.
