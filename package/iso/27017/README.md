# ISO/IEC 27017 - Information security controls for cloud services

ISO/IEC 27017 gives guidance on information security controls for cloud services, based on
ISO/IEC 27002. It is published jointly by ISO and IEC and applies to cloud service providers and cloud
service customers.

## What it includes

- **Cloud guidance for ISO/IEC 27002 controls:** Cloud-specific implementation guidance for existing
  controls.
- **Additional cloud controls:** Controls specific to cloud services, such as shared roles and
  responsibilities and virtual environment separation.
- **Provider and customer view:** Guidance for both the cloud service provider and the cloud service
  customer.
