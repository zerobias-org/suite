# Adobe Common Controls Framework (CCF)

The Common Controls Framework (CCF) is a set of security processes and controls developed by Adobe.
Adobe consolidated the requirements of common cloud security certifications and regulations into
one set of controls, and has released the framework publicly as open source.

## What it includes

- **Common controls:** A single control set that maps to the requirements of multiple industry
  standards and certifications.
- **Control domains:** Controls grouped into domains such as asset management, change management,
  identity and access management, incident response, risk management and vulnerability management.
- **Framework mappings:** Mappings from each control to the standards it helps satisfy.
