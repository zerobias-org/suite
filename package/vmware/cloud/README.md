# VMware Cloud

VMware Cloud is VMware's family of private and hybrid cloud infrastructure products, centered on
VMware Cloud Foundation (VCF). VCF is a private cloud platform that combines compute, storage,
networking, Kubernetes, management and security.

## What it includes

- **Compute:** VMware vSphere, including the vSphere Kubernetes Service.
- **Storage and networking:** VMware vSAN and VMware NSX.
- **Operations and automation:** VMware Cloud Foundation Operations and VMware Cloud Foundation
  Automation.
- **Add-on services:** Advanced services for VCF, such as VCF Private AI Services.
