# Insurance Data Security Model Law (MDL-668)

The Insurance Data Security Model Law (MDL-668) is a model law from the National Association of Insurance
Commissioners (NAIC). It sets data security standards for insurers and other entities licensed by
state insurance departments, which states can adopt into their own law.

## What it includes

- **Information security program:** A written program based on a risk assessment, with board oversight
  and oversight of third-party service providers.
- **Risk assessment:** Identifying and assessing threats to nonpublic information and information
  systems.
- **Cybersecurity event investigation:** Requirements to investigate suspected cybersecurity events.
- **Notification:** Notifying the insurance commissioner of cybersecurity events.
- **Annual certification:** Certifying compliance to the commissioner.
