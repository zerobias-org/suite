# CIS Benchmarks

The CIS Benchmarks are consensus-developed secure configuration guidelines published by the Center
for Internet Security (CIS). They cover many technologies and are used to harden systems against
common attacks.

## What it includes

- **Technology coverage:** Benchmarks for operating systems, cloud providers, server software,
  network devices, desktop software and mobile devices.
- **Configuration recommendations:** Specific settings, each with a rationale, audit steps and
  remediation steps.
- **Profiles:** Levels of recommendations that balance security against operational impact.
