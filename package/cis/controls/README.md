# CIS Controls

The CIS Critical Security Controls (CIS Controls) are a prioritized set of cyber defense
safeguards published by the Center for Internet Security (CIS).

## What it includes

- **Controls:** Top-level controls such as inventory of enterprise and software assets, data
  protection, secure configuration, account and access management, and vulnerability management.
- **Safeguards:** Specific actions under each control.
- **Implementation Groups:** IG1, IG2 and IG3, which prioritize safeguards by an enterprise's
  risk profile and resources.
