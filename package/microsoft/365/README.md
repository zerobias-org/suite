# Microsoft 365

Microsoft 365 is Microsoft's family of productivity, collaboration and cloud services for individuals and
organizations.

## What it includes

- **Office apps:** Word, Excel, PowerPoint and Outlook.
- **Collaboration:** Microsoft Teams, SharePoint and OneDrive.
- **Email:** Exchange Online.
- **Administration and security:** Admin center, identity, device management and compliance tools.
