# Microsoft Defender

Microsoft Defender is Microsoft's family of security products for protecting endpoints, identities,
email, cloud apps and cloud workloads.

## What it includes

- **Defender for Endpoint:** Endpoint detection and response for devices.
- **Defender for Office 365:** Protection for email and collaboration tools.
- **Defender for Identity:** Detection of identity-based threats.
- **Defender for Cloud:** Security posture management and workload protection for cloud environments.
- **Defender XDR:** Correlated detection and response across these products.
