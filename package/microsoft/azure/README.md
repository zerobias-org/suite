# Microsoft Azure

Microsoft Azure is Microsoft's cloud computing platform for building, deploying and managing
applications and infrastructure.

## What it includes

- **Compute:** Virtual machines, containers, Kubernetes and serverless functions.
- **Storage and databases:** Object, file and disk storage and managed databases.
- **Networking:** Virtual networks, load balancing and connectivity services.
- **Security and management:** Monitoring, policy, key management and security services.
