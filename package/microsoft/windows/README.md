# Microsoft Windows

Microsoft Windows is Microsoft's operating system family for personal computers and servers.

## What it includes

- **Windows client:** The desktop operating system for PCs and laptops.
- **Windows Server:** The server operating system for on-premises and cloud workloads.
- **Security features:** Built-in features such as Microsoft Defender Antivirus, BitLocker and Windows
  Hello.
- **Management:** Tools for deploying, updating and configuring Windows across an organization.
