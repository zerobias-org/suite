# IEC TR 60601-4-5:2021

IEC TR 60601-4-5 is a technical report titled "Medical electrical equipment – Part 4-5:
Guidance and interpretation – Safety-related technical security specifications". It is
published by the International Electrotechnical Commission (IEC).

## What it includes

- **Security specifications:** Technical specifications for security features of medical
  devices used in medical IT networks.
- **Security capability levels:** Capability levels for devices, built on the foundational
  requirements of IEC TS 62443-1-1.
- **Network integration:** Support for placing devices in security zones and conduits.
- **Scope:** Medical devices with external data interfaces; in-vitro diagnostic devices are
  out of scope.
