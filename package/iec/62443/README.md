# IEC 62443-4-2:2019

IEC 62443-4-2 is part of the IEC 62443 series on security for industrial automation and
control systems (IACS). It sets technical security requirements for IACS components and is
published by the International Electrotechnical Commission (IEC).

## What it includes

- **Component types:** Requirements for software applications, embedded devices, host devices
  and network devices.
- **Foundational requirements:** Requirements grouped under the seven IEC 62443 foundational
  requirements, such as identification and authentication control and system integrity.
- **Security levels:** Component requirements and enhancements mapped to security capability
  levels.
