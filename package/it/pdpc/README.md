# Personal Data Protection Code

The Personal Data Protection Code (Legislative Decree No. 196 of 30 June 2003) is Italy's national data
protection law. It was amended by Legislative Decree No. 101 of 10 August 2018 to align it with the EU
General Data Protection Regulation (GDPR), and it is supervised by the Garante per la protezione dei
dati personali.

## What it includes

- **GDPR supplementary rules:** National provisions that complement the GDPR in Italy.
- **Specific processing situations:** Rules for sectors such as health, employment, journalism and
  research.
- **Electronic communications:** Rules implementing the ePrivacy Directive (2002/58/EC).
- **Supervisory authority and remedies:** The Garante's role, complaints, judicial remedies and
  sanctions.
