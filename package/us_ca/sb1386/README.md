# California SB 1386 (Security Breach Notification)

California Senate Bill 1386 is the California state law that requires businesses and state agencies
to notify California residents when their unencrypted personal information is acquired by an
unauthorized person. It added the breach notification sections of the California Civil Code.

## What it includes

- **Breach notification:** Notice to California residents whose unencrypted personal information
  was, or is reasonably believed to have been, acquired without authorization.
- **Personal information:** A definition of covered personal information.
- **Timing and method:** Notice in the most expedient time possible, with rules for substitute
  notice.
