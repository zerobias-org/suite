# Atlassian Cloud

Atlassian Cloud is the set of Atlassian's software products delivered as hosted (SaaS) services,
used for project tracking, documentation, service management and software development.

## What it includes

- **Jira:** Project and issue tracking.
- **Confluence:** Team documentation and knowledge sharing.
- **Jira Service Management:** IT and customer service management.
- **Bitbucket Cloud:** Git code hosting and CI/CD.
- **Trello and Loom:** Visual task boards and video messaging.
