# CISA Cross-Sector Cybersecurity Performance Goals (CPG)

The Cross-Sector Cybersecurity Performance Goals (CPGs) are a set of baseline cybersecurity practices
published by the U.S. Cybersecurity and Infrastructure Security Agency (CISA). They are intended to help
critical infrastructure owners and operators prioritize high-impact security measures.

## What it includes

- **Goals by function:** goals aligned to the NIST Cybersecurity Framework functions, including
  Govern
- **Ratings:** cost, impact and ease of implementation for each goal
- **Sector-specific goals:** additional goals for selected critical infrastructure sectors
