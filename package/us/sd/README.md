# TSA Security Directive 1580/82-2022-01 (Rail Cybersecurity)

Security Directive 1580/82-2022-01, Rail Cybersecurity Mitigation Actions and Testing, is issued by
the U.S. Transportation Security Administration (TSA). It requires covered freight and passenger
rail owners and operators to put cybersecurity measures in place.

## What it includes

- **Cybersecurity implementation plan:** A plan, approved by TSA, describing the measures the owner
  or operator will take.
- **Mitigation measures:** Network segmentation, access control, continuous monitoring and detection,
  and timely patching of critical systems.
- **Assessment program:** A cybersecurity assessment program to test and audit the measures.
