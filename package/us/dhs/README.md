# CISA Trusted Internet Connections (TIC) 3.0 Security Capabilities Catalog

The TIC 3.0 Security Capabilities Catalog is published by the Cybersecurity and Infrastructure Security
Agency (CISA), part of the U.S. Department of Homeland Security. It lists the security capabilities
federal agencies use to secure network traffic under the Trusted Internet Connections program.

## What it includes

- **Universal security capabilities:** enterprise-level capabilities that apply across all use cases
- **Policy enforcement point capabilities:** capabilities applied to specific traffic, grouped by
  area such as email, web, networking and data protection
- **Use case alignment:** capabilities referenced by TIC 3.0 use cases
