# National Industrial Security Program Operating Manual (NISPOM)

The National Industrial Security Program Operating Manual (NISPOM) sets the requirements U.S.
government contractors must follow to protect classified information. It is now issued as a
federal regulation, 32 CFR Part 117, and is overseen by the Defense Counterintelligence and Security
Agency (DCSA) for the Department of Defense.

## What it includes

- **Clearances:** Requirements for entity (facility) eligibility and personnel security clearances.
- **Safeguarding:** Protection, marking, storage and transmission of classified information.
- **Insider threat and reporting:** Insider threat programs and required reports to the government.
- **Information systems:** Security requirements for systems that process classified information.
