# Cybersecurity Maturity Model Certification (CMMC)

The Cybersecurity Maturity Model Certification (CMMC) program is run by the U.S. Department of Defense
(DoD). It verifies that defense contractors protect Federal Contract Information and Controlled
Unclassified Information, and is codified at 32 CFR Part 170.

## What it includes

- **Level 1:** basic safeguarding requirements from FAR 52.204-21
- **Level 2:** security requirements from NIST SP 800-171
- **Level 3:** selected enhanced requirements from NIST SP 800-172
- **Assessments:** self-assessments, third-party (C3PAO) and government assessments depending on
  level
