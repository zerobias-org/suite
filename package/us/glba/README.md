# Gramm-Leach-Bliley Act (GLBA) - 16 CFR Part 314

The Standards for Safeguarding Customer Information (16 CFR Part 314), known as the Safeguards
Rule, is the Federal Trade Commission regulation that implements the data security provisions of
the Gramm-Leach-Bliley Act for financial institutions under FTC jurisdiction.

## What it includes

- **Information security program:** A written program with administrative, technical and physical
  safeguards for customer information.
- **Qualified individual and risk assessment:** A designated person to oversee the program and a
  written risk assessment.
- **Safeguards:** Required controls such as access control, encryption, multi-factor
  authentication, monitoring and staff training.
- **Service providers and reporting:** Oversight of service providers, incident response planning
  and notification of certain security events to the FTC.
