# Data Privacy Framework (DPF)

The Data Privacy Framework (DPF) program is administered by the U.S. Department of Commerce. It lets
U.S. organizations self-certify to a set of privacy principles to receive personal data from the EU, the UK
and Switzerland.

## What it includes

- **EU-U.S. DPF:** framework for transfers of personal data from the European Union
- **UK Extension to the EU-U.S. DPF:** transfers from the United Kingdom
- **Swiss-U.S. DPF:** transfers from Switzerland
- **DPF Principles:** notice, choice, onward transfer, security, data integrity, access and recourse
