# Defence Standard 05-138: Cyber Security for Defence Suppliers

Def Stan 05-138 sets the cyber security requirements that suppliers to the UK Ministry of
Defence (MOD) must meet. It is published by the MOD and used with the Defence Cyber
Protection Partnership (DCPP).

## What it includes

- **Cyber risk profiles:** Requirements scaled to the cyber risk level of a contract.
- **Security controls:** Controls suppliers must have in place for each risk profile.
- **Supply chain:** Flow-down of requirements to subcontractors.
