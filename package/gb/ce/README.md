# Cyber Essentials

Cyber Essentials is a UK government-backed certification scheme that helps organizations
protect against common cyber attacks. It is run by the UK National Cyber Security Centre
(NCSC).

## What it includes

- **Technical controls:** Firewalls, secure configuration, security update management, user
  access control and malware protection.
- **Cyber Essentials:** Certification based on a verified self-assessment.
- **Cyber Essentials Plus:** Certification that adds hands-on technical verification.
