# Cyber Assessment Framework (CAF)

The Cyber Assessment Framework is a framework for assessing how well an organization manages
cyber risk to its essential functions. It is published by the UK National Cyber Security
Centre (NCSC).

## What it includes

- **Objective A:** Managing security risk.
- **Objective B:** Protecting against cyber attack.
- **Objective C:** Detecting cyber security events.
- **Objective D:** Minimising the impact of cyber security incidents.
- **Principles and outcomes:** Each objective breaks into principles, contributing outcomes
  and indicators of good practice.
