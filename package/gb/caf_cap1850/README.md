# Cyber Assessment Framework for Aviation Guidance (CAP1850)

CAP1850 is guidance from the UK Civil Aviation Authority (CAA) on applying the NCSC Cyber
Assessment Framework (CAF) in the aviation sector. It supports the CAA's cyber security
oversight of aviation organizations.

## What it includes

- **CAF for aviation:** Guidance on the CAF objectives, principles and outcomes in an
  aviation context.
- **Self-assessment:** Guidance for organizations completing a CAF assessment.
- **Oversight link:** Use of the CAF within the CAA cyber security oversight process.
