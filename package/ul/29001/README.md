# UL 2900-1 Software Cybersecurity for Network-Connectable Products

UL 2900-1 is a standard published by UL that sets general software cybersecurity requirements for
network-connectable products. It is the first part of the UL 2900 series, which adds industry-specific
parts.

## What it includes

- **Documentation requirements:** information the product vendor must provide about the product and
  its design
- **Risk controls:** requirements for access control, authentication and protection of sensitive
  data
- **Vulnerability and malware testing:** testing for known vulnerabilities, malware and exploitable
  weaknesses
- **Software weakness analysis:** analysis of source and binary code for common weaknesses
