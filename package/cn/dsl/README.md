# Data Security Law of the People's Republic of China

The Data Security Law is a national law of the People's Republic of China. It regulates data
processing activities and data security, and sets up a system for classifying and protecting data
by importance.

## What it includes

- **Data classification:** A categorized, tiered data protection system, including "important
  data" and "core data".
- **Data security obligations:** Security management, risk monitoring and incident handling duties
  for organizations that process data.
- **Security review and export control:** National security review of data activities and export
  controls on certain data.
- **Government data:** Security and openness of government data.
- **Legal liability:** Penalties for violations.
