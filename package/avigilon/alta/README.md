# Avigilon Alta

Avigilon Alta is Avigilon's cloud-based physical security product family. It combines access
control and video security managed from the cloud.

## What it includes

- **Alta Access:** Cloud access control management with mobile and remote management.
- **Alta Video:** Cloud-native video security software.
- **Alta Protect:** Site monitoring using Alta cameras and Alta Video.
- **Alta Visitor and Alta Mailroom:** Visitor management and package logging.
- **Hardware:** Cameras, access control readers, panels and cloud connectors.
