# Secure Code Alliance (SCA)

The Secure Code Alliance is a program for certifying secure software development, created by
Secure Concepts Group. The Cyber AB is its accreditation body, and the SCF Assessor and
Instructor Certification Organization (SAICO) runs its individual credentials.

## What it includes

- **CODE certification:** The Certified Organization for Development Excellence
  certification for software development organizations, offered at three levels.
- **Assessments:** Assessments by accredited SCF Third-Party Assessment Organizations,
  reported in a Report on Conformity.
- **Individual credentials:** SCA Practitioner and SCA Architect certifications run by SAICO.
- **Reference frameworks:** CODE levels draw on CISA's Secure Software Development
  Attestation Form and NIST SP 800-218 (SSDF).
