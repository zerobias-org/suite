# OpenCRE (Open Common Requirement Enumeration)

OpenCRE is an open catalog that links security requirements across standards and guidelines
through shared topics called Common Requirements (CREs). It is developed as an open source
project in the OWASP community.

## What it includes

- **Common Requirements:** A hierarchy of security topics, each with a stable identifier.
- **Mappings:** Links from each CRE to related sections of standards such as OWASP ASVS, NIST
  SP 800-53, ISO 27001 and CWE.
- **Search and browsing:** A website for finding a topic and the matching parts of each standard.
