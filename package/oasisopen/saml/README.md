# Security Assertion Markup Language (SAML)

SAML is an XML-based standard for exchanging authentication, attribute and authorization
information between parties, widely used for web single sign-on. It is an OASIS Open standard.

## What it includes

- **Core:** Syntax and semantics of assertions and request/response protocols.
- **Bindings:** How SAML messages are carried over transports such as HTTP.
- **Profiles:** Use cases such as Web Browser Single Sign-On and Single Logout.
- **Metadata:** Configuration data exchanged between identity and service providers.
