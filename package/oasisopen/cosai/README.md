# Coalition for Secure AI (CoSAI)

The Coalition for Secure AI (CoSAI) is an open project hosted by OASIS Open that develops
practical security guidance for AI systems, including agentic AI.

## What it includes

- **Software Supply Chain Security for AI Systems:** Securing the AI supply chain.
- **Preparing Defenders for a Changing Security Landscape:** Helping defenders address AI-related
  threats.
- **AI Security Risk Governance:** Governance of AI security risk.
- **Secure Design Patterns for Agentic Systems:** Design guidance for agentic AI systems.
