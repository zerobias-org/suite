# Control Objectives for Information and Related Technologies (COBIT)

COBIT is ISACA's framework for the governance and management of enterprise information and technology.
It helps organizations set IT-related objectives, assign responsibilities and measure performance.

## What it includes

- **Governance and management objectives:** Forty objectives grouped into five domains.
- **Design guidance:** How to tailor a governance system to an enterprise's context and priorities.
- **Implementation guidance:** A roadmap for putting the governance system in place and improving it.
- **Assessment and performance management:** Methods for assessing governance and process performance.
