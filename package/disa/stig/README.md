# Security Technical Implementation Guides (STIGs)

STIGs are configuration standards for securing information systems and software used by the
U.S. Department of Defense, published by the Defense Information Systems Agency (DISA).

## What it includes

- **STIGs:** Product-specific configuration requirements for operating systems, network
  devices, applications and other technologies.
- **Security Requirements Guides (SRGs):** Technology-level requirements that STIGs are
  derived from.
- **SCAP content:** Benchmarks for automated checking of STIG settings.
- **Tools:** Viewers and other tools for working with STIGs.
