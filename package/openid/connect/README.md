# OpenID Connect

OpenID Connect is an identity layer on top of the OAuth 2.0 protocol that lets applications
verify a user's identity and obtain basic profile information. It is developed by the OpenID
Foundation.

## What it includes

- **Core:** Authentication flows, the ID Token and the UserInfo endpoint.
- **Discovery:** How clients find an OpenID Provider's configuration.
- **Dynamic Client Registration:** How clients register with an OpenID Provider.
- **Session management and logout:** Specifications for tracking and ending sessions.
