# Federal Risk and Authorization Management Program (FedRAMP)

FedRAMP is a U.S. government program that standardizes the security assessment,
authorization and continuous monitoring of cloud products used by federal agencies. It is
managed by the U.S. General Services Administration (GSA).

## What it includes

- **Security baselines:** Control baselines based on NIST SP 800-53.
- **Authorization:** Processes for cloud service providers to obtain a FedRAMP
  authorization.
- **Third-party assessment:** Assessments by accredited Third Party Assessment
  Organizations (3PAOs).
- **Continuous monitoring:** Ongoing security reporting after authorization.
- **Marketplace:** A public list of FedRAMP cloud services.
