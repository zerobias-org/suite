# NIST SP 800-160 - Systems Security Engineering

NIST Special Publication 800-160 is a series on systems security engineering: building security and
resilience into systems through engineering processes. It is published by the U.S. National Institute
of Standards and Technology (NIST).

## What it includes

- **Volume 1, Engineering Trustworthy Secure Systems:** Security considerations integrated into systems
  engineering life cycle processes.
- **Volume 2, Developing Cyber-Resilient Systems:** A cyber resiliency engineering framework with goals,
  objectives, techniques and design principles.
