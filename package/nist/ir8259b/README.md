# NIST IR 8259B - IoT Non-Technical Supporting Capability Core Baseline

NIST Interagency Report 8259B defines non-technical capabilities that IoT device manufacturers
and others should provide to support device cybersecurity. It complements NIST IR 8259A and is
published by the National Institute of Standards and Technology (NIST).

## What it includes

- **Documentation:** Cybersecurity information about the device and its development.
- **Information and query reception:** Ways to receive cybersecurity questions and reports.
- **Information dissemination:** Sharing cybersecurity information, such as vulnerabilities and
  updates, with customers.
- **Education and awareness:** Helping customers understand and use the device's security
  features.
