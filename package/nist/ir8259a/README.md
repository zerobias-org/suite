# NIST IR 8259A - IoT Device Cybersecurity Capability Core Baseline

NIST Interagency Report 8259A defines a baseline set of technical cybersecurity capabilities
that IoT devices should generally support. It is published by the National Institute of
Standards and Technology (NIST).

## What it includes

- **Device identification:** The device can be uniquely identified.
- **Device configuration:** Authorized entities can change the device's software configuration.
- **Data protection and logical access to interfaces:** Protect stored and sent data, and limit
  access to local and network interfaces.
- **Software update:** The device's software can be updated securely.
- **Cybersecurity state awareness:** The device can report on its cybersecurity state.
