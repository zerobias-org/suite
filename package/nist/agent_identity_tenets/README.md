# Design Tenets for Agent Identity Management Systems

A set of proposed design tenets from the National Institute of Standards and Technology (NIST)
for the identity, authentication and authorization of software and AI agents. It was published
as a post on the NIST Cybersecurity Insights blog, not as a numbered NIST publication.

## What it includes

- **Identity and delegation:** Distinct agent identification, and linking agents to the parties
  that delegate to them, with attenuated authority.
- **Authorization:** Least and zero standing privilege; short-lived, dynamic and revocable
  authorization; deterministic access decisions.
- **Control:** Human-in-the-loop triggers, mandates and constraints, and separation of policy
  from agent reasoning.
- **Oversight:** Continuous monitoring and immutable evidence of agent actions.
