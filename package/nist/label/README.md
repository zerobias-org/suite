# NIST Recommended Criteria for Cybersecurity Labeling of Consumer Software

A NIST Cybersecurity White Paper that recommends criteria for a consumer software cybersecurity
labeling program, to help consumers make informed choices about software. It is published by
the National Institute of Standards and Technology (NIST).

## What it includes

- **Baseline technical criteria:** Claims about the software and the security practices used to
  develop and maintain it.
- **Label approach:** How a label should present cybersecurity information to consumers.
- **Conformity assessment:** How developers attest that software meets the criteria.
- **Consumer education:** Recommendations for helping consumers understand the label.

## Official resources
