# NICE Workforce Framework for Cybersecurity

NICE (National Initiative for Cybersecurity Education) is a program led by the National
Institute of Standards and Technology (NIST) for cybersecurity education, training and workforce
development. Its main artifact is the NICE Workforce Framework for Cybersecurity (SP 800-181).

## What it includes

- **Task, Knowledge and Skill statements:** Building blocks that describe cybersecurity work and
  what a learner needs.
- **Work Roles:** Groupings of tasks for a cybersecurity job function.
- **Competency Areas:** Clusters of knowledge and skills in a domain.
