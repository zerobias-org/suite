# NIST 800-172A

NIST Special Publication 800-172A, Assessing Enhanced Security Requirements for Controlled Unclassified
Information, gives assessment procedures for the enhanced security requirements in NIST SP 800-172. It
is published by the U.S. National Institute of Standards and Technology (NIST).

## What it includes

- **Assessment procedures:** A procedure for each SP 800-172 enhanced security requirement.
- **Assessment methods:** Examine, interview and test methods and the objects they apply to.
- **Determination statements:** Statements an assessor uses to decide if a requirement is met.
