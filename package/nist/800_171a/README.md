# NIST SP 800-171A - Assessing Security Requirements for Controlled Unclassified Information

NIST Special Publication 800-171A gives assessment procedures for the security requirements in
NIST SP 800-171. It is published by the U.S. National Institute of Standards and Technology (NIST).

## What it includes

- **Assessment procedures:** A procedure for each SP 800-171 security requirement.
- **Assessment methods:** Examine, interview and test methods and the objects they apply to.
- **Determination statements:** Statements that an assessor uses to decide if a requirement is met.
