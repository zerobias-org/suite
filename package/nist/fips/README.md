# NIST Federal Information Processing Standards (FIPS)

Federal Information Processing Standards (FIPS) are standards for U.S. federal computer systems,
developed by the National Institute of Standards and Technology (NIST). Many cover cryptography
and security requirements.

## What it includes

- **Cryptographic algorithms:** For example FIPS 197 (AES), FIPS 180-4 (Secure Hash Standard)
  and FIPS 186-5 (Digital Signature Standard).
- **Post-quantum cryptography:** FIPS 203, 204 and 205.
- **Cryptographic modules:** FIPS 140-3, security requirements for cryptographic modules.
- **Security categorization and requirements:** FIPS 199 and FIPS 200.
