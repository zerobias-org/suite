# NIST SP 800-172 - Enhanced Security Requirements for Controlled Unclassified Information

NIST Special Publication 800-172 gives enhanced security requirements for protecting Controlled
Unclassified Information (CUI) associated with critical programs or high value assets. It supplements
NIST SP 800-171 and is published by the U.S. National Institute of Standards and Technology (NIST).

## What it includes

- **Enhanced security requirements:** Requirements that add to the SP 800-171 families.
- **Advanced persistent threat focus:** Protection against attacks by advanced persistent threats.
- **Design strategies:** Penetration-resistant architecture, damage-limiting operations, and designing
  for cyber resiliency.
