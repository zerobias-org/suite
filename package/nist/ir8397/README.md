# NIST IR 8397 - Minimum Standards for Developer Verification of Software

NIST Interagency Report 8397, "Guidelines on Minimum Standards for Developer Verification of
Software", recommends verification techniques that software developers should use. It is
published by the National Institute of Standards and Technology (NIST).

## What it includes

- **Threat modeling:** Identify design-level security issues.
- **Automated testing:** Static code scanning, dynamic and black-box testing, and fuzzing.
- **Secrets and dependencies:** Check for hardcoded secrets and verify included libraries and
  components.
- **Regression testing:** Use historical test cases to catch reintroduced bugs.
