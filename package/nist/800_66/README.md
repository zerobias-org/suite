# NIST SP 800-66 Rev. 2 - Implementing the HIPAA Security Rule

NIST Special Publication 800-66 Revision 2 is a cybersecurity resource guide for organizations
implementing the HIPAA Security Rule, which protects electronic protected health information
(ePHI). It is published by the National Institute of Standards and Technology (NIST).

## What it includes

- **Risk assessment and risk management:** Guidance for assessing and managing risks to ePHI.
- **Security Rule standards:** Key activities and sample questions for the administrative,
  physical and technical safeguards.
- **Organizational and documentation requirements:** Business associate contracts, policies,
  procedures and documentation.
