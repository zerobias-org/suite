# NIST SP 800-218 (SSDF)

NIST Special Publication 800-218, the Secure Software Development Framework (SSDF), recommends practices
for reducing vulnerabilities in software. It is published by the U.S. National Institute of Standards
and Technology (NIST).

## What it includes

- **Prepare the Organization (PO):** People, processes and technology for secure development.
- **Protect the Software (PS):** Protecting software components from tampering and unauthorized access.
- **Produce Well-Secured Software (PW):** Producing software with minimal security vulnerabilities.
- **Respond to Vulnerabilities (RV):** Finding and fixing residual vulnerabilities after release.
