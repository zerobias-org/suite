# SPARTA Countermeasures

SPARTA (Space Attack Research and Tactic Analysis) is a knowledge base of threats to spacecraft,
published by The Aerospace Corporation. This suite covers SPARTA's countermeasures, which describe ways to
prevent or mitigate the techniques in the SPARTA matrix.

## What it includes

- **SPARTA matrix:** tactics and techniques an adversary may use against space systems
- **Countermeasures:** defensive measures mapped to the techniques they address
- **Control mappings:** links from countermeasures to related security controls
