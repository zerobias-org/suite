# New York SHIELD Act (S5575B)

The Stop Hacks and Improve Electronic Data Security (SHIELD) Act, enacted as New York Senate Bill
S5575B, is a New York state law. It expanded New York's data breach notification law and added data
security requirements for businesses that hold private information of New York residents.

## What it includes

- **Breach notification:** A broader definition of private information and of a breach, including
  unauthorized access.
- **Reasonable safeguards:** A requirement to maintain reasonable administrative, technical and
  physical safeguards.
- **Enforcement:** Enforcement by the New York Attorney General.
