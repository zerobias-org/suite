# TISAX / VDA ISA

TISAX (Trusted Information Security Assessment Exchange) is the assessment and exchange mechanism for
information security in the automotive industry, operated by the ENX Association. Assessments are based on
the VDA Information Security Assessment (ISA) catalogue.

## What it includes

- **Information security:** core ISA requirements for protecting information
- **Prototype protection:** additional requirements for handling vehicle prototypes
- **Data protection:** requirements for processing personal data on behalf of others
- **Assessment levels:** levels that set how thoroughly a site is assessed
