# Royal Decree 311/2022 – National Security Framework (ENS)

Royal Decree 311/2022 regulates Spain's National Security Framework (Esquema Nacional de
Seguridad, ENS). It sets the security requirements for information systems of the Spanish
public sector and of providers that support it. It is published in the Boletín Oficial del
Estado (BOE) as BOE-A-2022-7191.

## What it includes

- **Basic principles and minimum requirements:** The principles and requirements that
  security policies must follow.
- **System categorisation:** Classification of systems into basic, medium and high categories.
- **Security measures:** Organisational, operational and protection measures (Annex II).
- **Conformity and incidents:** Security audits, conformity statements and certification, and
  incident response.
