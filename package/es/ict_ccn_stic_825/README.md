# ICT Security Guide CCN-STIC 825

CCN-STIC 825 is a guide in the CCN-STIC 800 series on Spain's National Security Framework
(ENS), published by the National Cryptologic Centre (Centro Criptológico Nacional, CCN). It
covers how ISO/IEC 27001 certifications relate to ENS compliance.

## What it includes

- **ENS and ISO/IEC 27001:** Guidance on using an ISO/IEC 27001 certification to support ENS
  compliance.
- **Control correspondence:** Comparison of ENS security measures with ISO/IEC 27001 controls.
- **Certification context:** Explanation of how the two certification schemes differ.
