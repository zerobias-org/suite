# Secure Controls Framework (SCF)

The Secure Controls Framework (SCF) is a free, comprehensive catalog of cybersecurity and data
privacy controls. It is designed as a "metaframework" that maps one set of controls to many laws,
regulations and frameworks.

## What it includes

- **Controls catalog:** Cybersecurity and privacy controls organized into domains.
- **Mappings:** Cross-references from SCF controls to external laws, regulations and frameworks.
- **Assessment objectives:** Criteria for assessing whether controls are implemented.
- **Supporting content:** Risk and threat catalogs and a maturity model.
