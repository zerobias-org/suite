# SLSA (Supply-chain Levels for Software Artifacts)

SLSA is a security framework of incrementally adoptable guidelines for software supply chain integrity.
It is developed as an open, industry-consensus specification under the Open Source Security Foundation
(OpenSSF).

## What it includes

- **Levels:** incremental levels that describe increasing supply chain guarantees
- **Build track:** requirements for producing artifacts on hardened, isolated build platforms
- **Provenance:** a format for describing how, where and from what an artifact was built
- **Verification:** guidance for checking artifacts and provenance before use
