# HITRUST CSF

The HITRUST CSF is a security and privacy framework that brings together requirements from
many standards and regulations. It is maintained by the HITRUST Alliance, which also runs an
assessment and certification program based on it.

## What it includes

- **Framework:** Security and privacy controls harmonized from multiple authoritative sources.
- **Validated assessments:** The e1, i1 and r2 assessments with different levels of
  assurance.
- **Assessor ecosystem:** Authorized External Assessor organizations and individual
  credentials such as CCSFP.
