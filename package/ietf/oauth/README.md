# OAuth 2.0

OAuth 2.0 is an authorization framework that lets a third-party application get limited
access to an HTTP service. It is defined in RFC 6749, published by the Internet Engineering
Task Force (IETF).

## What it includes

- **Roles:** Resource owner, client, authorization server and resource server.
- **Grant types:** Authorization code, implicit, resource owner password credentials and
  client credentials grants.
- **Tokens:** Access tokens and refresh tokens.
- **Bearer tokens:** Use of bearer tokens, defined in the companion RFC 6750.

## Official resources
