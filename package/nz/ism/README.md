# New Zealand Information Security Manual (NZISM)

The NZISM is the New Zealand Government's manual on information assurance and information
systems security for government agencies. It is developed and maintained by the Government
Communications Security Bureau (GCSB) through its National Cyber Security Centre (NCSC).

## What it includes

- **Governance and roles:** Responsibilities for information security within agencies.
- **System certification and accreditation:** Approving systems for operation.
- **Technical controls:** Requirements for areas such as network security, access control,
  cryptography and software security.
- **Protective Security Requirements:** The NZISM is part of the government's PSR framework.
