# NZ Health Information Security Framework (HISF)

The Health Information Security Framework (HISO 10029) sets guidelines that New Zealand health
sector organisations should follow to secure their systems and health information. It is
published by Health New Zealand | Te Whatu Ora.

## What it includes

- **Core framework (HISO 10029):** Security requirements for the health sector.
- **Guidance for hospitals:** For public and private hospitals (HISO 10029.1).
- **Guidance for micro to small organisations:** For small providers (HISO 10029.2).
- **Guidance for medium to large organisations:** For larger providers (HISO 10029.3).
- **Guidance for suppliers:** For suppliers to the health sector (HISO 10029.4).
