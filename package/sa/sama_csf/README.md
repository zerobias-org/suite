# SAMA Cyber Security Framework

The Cyber Security Framework is issued by the Saudi Central Bank (SAMA, formerly the Saudi Arabian
Monetary Authority) for the financial institutions it regulates. It defines cybersecurity controls and a
maturity model for assessing them.

## What it includes

- **Cyber security leadership and governance:** strategy, policy, roles, awareness and training
- **Cyber security risk management and compliance:** risk assessment, regulatory compliance and
  audit
- **Cyber security operations and technology:** access, application, network, monitoring and
  incident controls
- **Third party cyber security:** outsourcing, cloud and contract requirements
- **Maturity model:** levels used to measure how well the controls are implemented
