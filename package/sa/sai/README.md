# Saudi Arabia IoT Cybersecurity Guidelines (CGIoT-1:2024)

CGIoT-1:2024 is a set of cybersecurity guidelines for Internet of Things (IoT) devices and deployments,
published by Saudi Arabia's National Cybersecurity Authority (NCA).

## What it includes

- **IoT device security:** guidance on securing connected devices across their lifecycle
- **Access and communication protection:** authentication, access control and protection of data in
  transit
- **Monitoring and maintenance:** updates, logging and handling of vulnerabilities in IoT
  environments
