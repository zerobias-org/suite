# Cloud Computing Compliance Criteria Catalogue (C5)

C5 is a catalogue of minimum security requirements for cloud services, published by the
German Federal Office for Information Security (BSI). Cloud providers use it to show their
security level through an independent audit.

## What it includes

- **Basic criteria:** Security requirements that cloud providers must meet.
- **Additional criteria:** Optional requirements for a higher level of protection.
- **Complementary customer criteria:** Controls the cloud customer is expected to have in
  place.
- **Attestation:** Rules for audits and attestation reports by independent auditors.
