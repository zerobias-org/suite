# Virginia Consumer Data Protection Act (VCDPA)

The Virginia Consumer Data Protection Act is a Virginia state consumer data privacy law, codified in
Chapter 53 of Title 59.1 of the Code of Virginia. It is enforced by the Virginia Attorney General.

## What it includes

- **Consumer rights:** Rights to access, correct, delete and port personal data, and to opt out of
  targeted advertising, sale and certain profiling.
- **Controller duties:** Privacy notices, data minimization, security and consent for processing
  sensitive data.
- **Processors:** Contract requirements between controllers and processors.
- **Data protection assessments:** Assessments for certain types of processing.
