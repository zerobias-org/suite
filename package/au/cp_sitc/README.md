# Code of Practice: Securing the Internet of Things for Consumers (Australia)

The Code of Practice: Securing the Internet of Things for Consumers is voluntary guidance from the
Australian Government for manufacturers of consumer IoT devices. It sets out 13 security
principles for devices and their associated services.

## What it includes

- **Credentials:** No duplicated default or weak passwords.
- **Vulnerability disclosure:** A policy for receiving and acting on vulnerability reports.
- **Software updates:** Keeping software securely updated.
- **Data protection:** Secure storage of credentials, secure communication and protection of
  personal data.
- **Resilience and usability:** Resilience to outages, monitoring of telemetry, easy deletion of
  personal data and easy, secure installation.
