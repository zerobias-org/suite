# MPA Content Security Best Practices Common Guidelines

The MPA Content Security Best Practices are the Motion Picture Association's standard controls for
securing film and television content at vendor facilities. They are maintained through the Trusted
Partner Network (TPN), an industry security initiative owned by the MPA. Compliance is voluntary.

## What it includes

- **Security controls:** Standard controls for protecting content handled by entertainment vendors.
- **Benchmark for vendors:** A minimum level of security preparedness vendors are expected to meet.
- **TPN assessments:** Assessments that compare a vendor's security to the best practices.
