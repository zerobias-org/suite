# Protection Profile for Application Software

The Protection Profile for Application Software (PP_APP) defines the security requirements used to
evaluate application software under the Common Criteria. It is published by the U.S. National
Information Assurance Partnership (NIAP).

## What it includes

- **Security problem definition:** Threats, assumptions and organizational security policies for
  application software.
- **Security functional requirements:** Requirements for areas such as cryptography, user data
  protection, secure configuration, trusted updates and secure communications.
- **Assurance activities:** The tests and evidence evaluators use to verify each requirement.
