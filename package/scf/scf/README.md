# Secure Controls Framework (SCF)

The Secure Controls Framework (SCF) is a free, open metaframework of cybersecurity and data privacy
controls maintained by the SCF Council. It maps its controls to many laws, regulations and frameworks so
one control set can cover several compliance obligations.

## What it includes

- **Control catalog:** cybersecurity and privacy controls grouped into domains
- **Mappings:** crosswalks from SCF controls to external laws, regulations and frameworks
- **Assessment objectives:** criteria for evaluating whether controls are implemented
- **Maturity model:** capability levels for measuring control maturity
