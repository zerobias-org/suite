# Japan Information System Security Management and Assessment Program (ISMAP)

ISMAP is the Japanese government's program for assessing and registering the security of cloud services
used by government agencies. Cloud services that pass an ISMAP assessment are listed on the ISMAP Cloud
Service List.

## What it includes

- **Control criteria:** The security requirements cloud services are assessed against.
- **Audits:** Assessments of cloud services by registered audit organizations.
- **ISMAP Cloud Service List:** The public register of assessed cloud services.
- **ISMAP-LIU:** A track for low-impact SaaS used by government.
