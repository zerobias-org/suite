# UN Regulation No. 155 - Cyber Security and Cyber Security Management System

UN Regulation No. 155 sets uniform provisions for the approval of vehicles with regard to cyber security
and the manufacturer's cyber security management system (CSMS). It was developed under UNECE's World
Forum for Harmonization of Vehicle Regulations (WP.29).

## What it includes

- **Cyber security management system:** manufacturer processes, responsibilities and governance for
  vehicle cyber risk
- **Vehicle type approval:** requirements a vehicle type must meet for cyber security approval
- **Threats and mitigations:** annexed catalogue of threats to vehicles and corresponding
  mitigations
- **Scope:** vehicle categories L, M, N and O fitted with at least one electronic control unit
