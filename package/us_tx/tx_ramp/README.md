# Texas Risk and Authorization Management Program (TX-RAMP)

The Texas Risk and Authorization Management Program (TX-RAMP) is run by the Texas Department of
Information Resources (DIR). It provides a standard approach for assessing and certifying cloud
computing services used by Texas state agencies.

## What it includes

- **Certification:** Security certification of cloud computing services that are in scope.
- **Certified services list:** A published list of cloud services certified through TX-RAMP.
- **Requests:** Processes for general, fast track and provisional extension requests.
- **Guidance:** A TX-RAMP security plan and guides for vendors and agencies.
