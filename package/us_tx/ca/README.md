# Texas Cybersecurity Act (HB 8, 2017)

The Texas Cybersecurity Act was enacted by the Texas Legislature as House Bill 8 in its 85th regular
session. It sets cybersecurity requirements for Texas state agencies and expands the role of the
Texas Department of Information Resources (DIR).

## What it includes

- **Information sharing:** An information sharing and analysis center run by DIR.
- **Cybersecurity council:** Changes to the state cybersecurity council.
- **Agency assessments:** Information security assessments of state agencies and data security plans
  for online and mobile applications.
- **Incidents:** Handling and reporting of cybersecurity risks and incidents, and changes to breach
  notification rules.
- **Elections:** A study of cyber attacks on election infrastructure.
