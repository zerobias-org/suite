# SPDX (Software Package Data Exchange)

SPDX is an open standard for communicating software bill of materials (SBOM) information, including
components, licenses, copyrights and security references. It is an open project of the Linux Foundation
and is also published as ISO/IEC 5962.

## What it includes

- **SPDX specification:** the data model and formats for describing software packages and files
- **SPDX License List:** standard identifiers for common open source licenses
- **License expressions:** a syntax for describing the licensing of a package or file
