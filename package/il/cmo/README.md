# Cybersecurity Methodology for an Organization

The Cyber Defense Methodology for an Organization (ICDM) is the Israel National Cyber Directorate's
(INCD) guidance for how organizations should manage cyber risk and defense. Version 1.0 adopts the
NIST Cybersecurity Framework 1.0 for use in the Israeli market.

## What it includes

- **NIST Cybersecurity Framework basis:** Defense requirements organized around the NIST Cybersecurity
  Framework.
- **Requirement guidance:** For each requirement, explanations, examples, links to implementation
  practices and templates.
- **Maturity model:** An organizational maturity model for measuring cyber defense.
