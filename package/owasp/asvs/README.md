# OWASP Application Security Verification Standard (ASVS)

The ASVS is a list of security requirements for designing, building and testing web
applications and services. It is an OWASP flagship project published by the OWASP Foundation.

## What it includes

- **Verification levels:** Three levels of increasing rigor for different risk profiles.
- **Requirement chapters:** Requirements grouped by area, such as authentication, session
  management, access control, input validation and cryptography.
- **Uses:** A basis for secure development, testing and procurement requirements.
