# OWASP Secure Pipeline Verification Standard (SPVS)

SPVS is a framework of verifiable security requirements for software delivery pipelines,
organized by maturity level. It is an OWASP project.

## What it includes

- **Plan:** Scope, objectives and security requirements for each iteration.
- **Develop:** Building security into code from the start.
- **Integrate:** Securely integrating new code into the main codebase.
- **Release:** Secure and compliant deployment to production.
- **Operate:** Maintaining and protecting production environments.
