# OWASP Top 10 Proactive Controls

The OWASP Top 10 Proactive Controls are ten security techniques that developers should include
in every software project. It is an OWASP project often used for developer training.

## What it includes

- **Ten controls:** Practices such as access control, cryptography, input validation and
  security logging and monitoring.
- **Per-control guidance:** Description, threats addressed and implementation advice.
