# OWASP Software Assurance Maturity Model (SAMM)

OWASP SAMM is a model for assessing and improving an organization's software security
practices. It is an OWASP flagship project.

## What it includes

- **Business functions:** Governance, Design, Implementation, Verification and Operations.
- **Security practices:** Each business function contains security practices with activities.
- **Maturity levels:** Three maturity levels per practice, used for assessment and roadmaps.
