# OWASP Automated Threats to Web Applications

This OWASP project names and classifies automated threats to web applications: misuse of
normal functionality by software, as opposed to exploitation of single vulnerabilities.

## What it includes

- **Threat ontology:** Named automated threats with OAT identifiers, such as credential
  stuffing, scraping, carding and account creation.
- **Handbook:** Descriptions, symptoms and countermeasures for each threat.
