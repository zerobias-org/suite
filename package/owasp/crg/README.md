# OWASP Code Review Guide

The OWASP Code Review Guide is a book on reviewing source code for security, written for
managers, developers and security professionals. It is an OWASP project.

## What it includes

- **Secure code review methodology:** How to plan and run security code reviews.
- **Review by vulnerability type:** What to look for in code for common weaknesses.
- **Integrating review into the SDLC:** Fitting code review into development processes.
