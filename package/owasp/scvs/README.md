# OWASP Software Component Verification Standard (SCVS)

SCVS is a framework for identifying activities, controls and best practices that reduce risk in
the software supply chain. It is an OWASP project.

## What it includes

- **Inventory:** Knowing which components are used.
- **Software Bill of Materials (SBOM):** Requirements for SBOMs.
- **Build environment and package management:** Securing how software is built and how
  packages are obtained.
- **Component analysis and pedigree:** Analyzing components and their provenance.
- **Levels:** Three verification levels.
