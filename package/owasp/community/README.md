# OWASP Community Pages

The OWASP Community Pages are a collection of security articles contributed by the OWASP
community. They are hosted by the OWASP Foundation.

## What it includes

- **Attacks:** Descriptions of common attack techniques.
- **Vulnerabilities:** Descriptions of common software weaknesses.
- **Controls:** Defensive techniques and countermeasures.
