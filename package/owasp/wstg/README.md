# OWASP Web Security Testing Guide (WSTG)

The WSTG is a guide for testing the security of web applications and web services. It is an
OWASP flagship project.

## What it includes

- **Testing framework:** How security testing fits into the development lifecycle.
- **Test cases:** Tests grouped by area, such as configuration, authentication, authorization,
  session management, input validation and business logic.
- **Reporting:** How to write up test findings.
