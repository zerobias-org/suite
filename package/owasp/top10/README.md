# OWASP Top 10

The OWASP Top 10 is an awareness document listing the most critical security risks to web
applications. It is an OWASP flagship project, updated periodically from industry data.

## What it includes

- **Risk categories:** Ten categories such as broken access control, injection and security
  misconfiguration.
- **Per-category guidance:** Description, examples, prevention and mapped CWEs.
