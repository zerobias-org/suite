# OWASP Dependency-Check

Dependency-Check is a Software Composition Analysis (SCA) tool that detects publicly disclosed
vulnerabilities in a project's dependencies. It is an OWASP project.

## What it includes

- **Dependency identification:** Identifies components and matches them to CPE identifiers.
- **Vulnerability matching:** Reports known vulnerabilities (CVEs) linked to those components.
- **Integrations:** Command-line tool and build plugins, such as Maven and Gradle.
