# OWASP Cheat Sheet Series

The OWASP Cheat Sheet Series is a collection of short, practical guides on specific application
security topics. It is an OWASP project written by application security practitioners.

## What it includes

- **Topic cheat sheets:** Guidance on topics such as authentication, session management, input
  validation, cryptographic storage and logging.
- **Indexes:** Cheat sheets mapped to other OWASP projects, such as ASVS and the Top 10.
