# OWASP Top 10 for Large Language Model Applications

The OWASP Top 10 for LLM Applications lists the most critical security risks in applications
built on large language models. It is part of the OWASP Gen AI Security Project.

## What it includes

- **Risk list:** Ten risks such as prompt injection, sensitive information disclosure and supply
  chain vulnerabilities.
- **Per-risk guidance:** A description, example attack scenarios and prevention measures for each
  risk.
