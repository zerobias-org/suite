# OWASP Mobile Application Security Verification Standard (MASVS)

The MASVS is a security standard for mobile apps, used by architects, developers and testers.
It is part of the OWASP Mobile Application Security (MAS) project.

## What it includes

- **Control groups:** MASVS-STORAGE, MASVS-CRYPTO, MASVS-AUTH, MASVS-NETWORK, MASVS-PLATFORM,
  MASVS-CODE, MASVS-RESILIENCE and MASVS-PRIVACY.
- **Related projects:** The Mobile Application Security Testing Guide (MASTG) describes how to
  test the controls.
