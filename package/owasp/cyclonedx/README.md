# OWASP CycloneDX

CycloneDX is a Bill of Materials (BOM) standard for describing software, hardware and services
and their supply chain. It is an OWASP flagship project and is also published by Ecma
International as ECMA-424.

## What it includes

- **SBOM:** Inventory of software components and their relationships.
- **Other BOM types:** For example SaaSBOM, hardware (HBOM), cryptography (CBOM) and machine
  learning (ML-BOM).
- **Vulnerability information:** VEX and vulnerability disclosure reports.
- **Formats:** JSON, XML and Protocol Buffers.
