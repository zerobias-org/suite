# AWS

Amazon Web Services (AWS) is Amazon's cloud computing platform. It offers on-demand infrastructure,
platform and managed services used to build and run applications.

## What it includes

- **Compute:** Virtual servers, containers and serverless functions (for example Amazon EC2 and
  AWS Lambda).
- **Storage and databases:** Object, block and file storage and managed databases (for example
  Amazon S3, Amazon RDS and Amazon DynamoDB).
- **Networking:** Virtual networks, content delivery and DNS (for example Amazon VPC).
- **Security and identity:** Identity and access management, encryption and monitoring services.
