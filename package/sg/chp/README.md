# MAS Cyber Hygiene Notices

The Monetary Authority of Singapore (MAS) issues legally binding Notices on Cyber Hygiene to the financial
institutions it regulates. They set a small set of mandatory baseline cybersecurity practices.

## What it includes

- **Administrative accounts:** securing and controlling privileged accounts
- **Security patches:** applying patches to address system vulnerabilities
- **Security standards:** written baseline security standards for systems
- **Network perimeter defence:** controls to restrict unauthorised network traffic
- **Malware protection and multi-factor authentication:** anti-malware measures and MFA for key
  access
