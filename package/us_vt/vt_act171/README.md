# Vermont Act 171 of 2018 (Data Broker Act)

Act 171 of 2018 is a Vermont state law on data brokers and consumer protection. It requires data
brokers to register with the Vermont Secretary of State and to protect the personal information
they hold.

## What it includes

- **Data broker registration:** Annual registration of data brokers with the Secretary of State,
  with required disclosures.
- **Information security program:** A duty for data brokers to maintain a written information
  security program.
- **Prohibited acquisition and use:** Limits on acquiring brokered personal information by fraud and
  using it for harmful purposes.
- **Credit security freeze:** Free credit report security freezes for consumers.
