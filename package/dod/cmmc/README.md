# Cybersecurity Maturity Model Certification (CMMC)

CMMC is a U.S. Department of Defense program for verifying that defense contractors protect
Federal Contract Information (FCI) and Controlled Unclassified Information (CUI). The program
rules are set in 32 CFR Part 170.

## What it includes

- **Level 1:** Basic safeguarding of FCI, based on FAR 52.204-21.
- **Level 2:** Protection of CUI, based on NIST SP 800-171.
- **Level 3:** Enhanced protection of CUI, based on selected NIST SP 800-172 requirements.
- **Assessments:** Self-assessments and third-party assessments by certified assessment
  organizations (C3PAOs), accredited by The Cyber AB.
