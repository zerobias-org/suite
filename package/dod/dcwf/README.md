# DoD Cyber Workforce Framework (DCWF)

The DoD Cyber Workforce Framework defines the work roles of the U.S. Department of Defense
cyber workforce. It is the basis for the DoD 8140 cyberspace workforce qualification program
(DoDM 8140.03).

## What it includes

- **Work roles:** Defined roles for the DoD cyber workforce.
- **Knowledge, skills, abilities and tasks:** The KSATs that describe each work role.
- **Workforce elements:** Groupings of work roles, such as IT, cybersecurity and cyber
  effects.
- **Qualification link:** Use of the work roles to set qualification requirements under
  DoD 8140.
