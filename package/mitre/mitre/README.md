# MITRE ATT&CK - NIST 800-53 mappings

The ATT&CK to NIST 800-53 mappings connect the security controls in NIST SP 800-53 to the adversary
techniques in MITRE ATT&CK. They are produced by the Center for Threat-Informed Defense, a
MITRE-operated research and development organization.

## What it includes

- **Control-to-technique mappings:** Which NIST SP 800-53 controls mitigate which ATT&CK techniques.
- **Control revisions:** Mappings for NIST SP 800-53 Revision 4 and Revision 5.
- **Mappings Explorer:** A web tool for browsing the mappings.
