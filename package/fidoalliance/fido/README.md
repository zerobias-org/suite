# FIDO

FIDO is a set of authentication standards based on public key cryptography, developed by the
FIDO Alliance. They let services replace password-only logins with phishing-resistant sign-in.

## What it includes

- **FIDO2:** The W3C Web Authentication (WebAuthn) specification and the FIDO Client to
  Authenticator Protocol (CTAP).
- **Passkeys:** FIDO credentials that replace passwords for sign-in.
- **UAF and U2F:** Earlier FIDO specifications for passwordless and second-factor
  authentication.
- **Certification:** Programs that certify products against FIDO specifications.
