# Google Workspace

Google Workspace is Google's suite of cloud productivity and collaboration apps for
organizations.

## What it includes

- **Communication:** Gmail, Google Chat and Google Meet.
- **Content and collaboration:** Google Drive, Docs, Sheets and Slides.
- **Scheduling:** Google Calendar.
- **Administration:** The Admin console for managing users, devices and security settings.
