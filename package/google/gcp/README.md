# Google Cloud

Google Cloud is Google's public cloud platform for building, deploying and running
applications and data workloads.

## What it includes

- **Compute:** Virtual machines, containers (Google Kubernetes Engine) and serverless
  services.
- **Storage and databases:** Object storage, managed relational and NoSQL databases.
- **Data and AI:** Analytics (such as BigQuery) and AI and machine learning services.
- **Security and identity:** Identity and access management and security services.
