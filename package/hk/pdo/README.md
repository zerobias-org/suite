# Personal Data (Privacy) Ordinance (Cap. 486)

The Personal Data (Privacy) Ordinance is Hong Kong's data protection law. It is enforced by
the Office of the Privacy Commissioner for Personal Data (PCPD).

## What it includes

- **Data Protection Principles:** Six principles on collection, accuracy and retention, use,
  security, openness, and access and correction.
- **Direct marketing:** Rules on using personal data for direct marketing.
- **Privacy Commissioner:** Powers of the PCPD to investigate and enforce.
- **Offences:** Criminal offences under the ordinance.
